Create game_repository.py with functions:
- list_games(venue_night_id: int | None = None) -> list[Game]
- get_game(id: int) -> Game | None
- create_game(venue_night_id: int, name: str, playlist_json: str, card_count: int) -> Game
- update_game(id: int, name: str, playlist_json: str, card_count: int, sort_order: int) -> Game
- delete_game(id: int) -> bool
- update_game_pdf_path(id: int, pdf_path: str) -> None

Game includes:
- game_uuid: Auto-generated UUID for API compatibility with existing game system
- playlist_json: Stored as JSON string, parsed on read
- pdf_path: Set after card generation

Create game_routes.py with FastAPI router:
- GET /api/prep/games - List games (query param: venue_night_id for filtering)
- GET /api/prep/games/{id} - Get single game with parsed playlist
- POST /api/prep/games - Create game (body: venue_night_id, name, playlist, card_count)
- PUT /api/prep/games/{id} - Update game
- DELETE /api/prep/games/{id} - Delete game
- POST /api/prep/games/parse-csv - Parse uploaded CSV file, return playlist JSON (for preview before save)

CSV parsing: Reuse logic from musicbingo_cards/csv_import.py. Import the parse_exportify_csv function or copy the parsing logic. Expected columns: Track Name, Artist Name(s).
Generate song_id as SHA256 hash of lowercase title+artist, truncated to 12 chars (same pattern as existing code).

In main.py:
- Import and include game_routes router
