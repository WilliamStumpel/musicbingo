<task type="auto">
  <name>Task 2: Create database models and schema</name>
  <files>musicbingo_api/src/musicbingo_api/db_models.py</files>
  <action>
Create db_models.py with dataclasses and schema DDL for:

**Venue table:**
- id: INTEGER PRIMARY KEY AUTOINCREMENT
- name: TEXT NOT NULL UNIQUE
- logo_path: TEXT (nullable, path to uploaded logo file)
- contact_info: TEXT (nullable, DJ contact info for cards)
- created_at: TEXT (ISO datetime)
- updated_at: TEXT (ISO datetime)

**VenueNight table:**
- id: INTEGER PRIMARY KEY AUTOINCREMENT
- venue_id: INTEGER NOT NULL REFERENCES venues(id) ON DELETE CASCADE
- date: TEXT NOT NULL (ISO date YYYY-MM-DD)
- status: TEXT NOT NULL DEFAULT 'draft' (draft, ready, completed)
- notes: TEXT (nullable)
- created_at: TEXT (ISO datetime)
- updated_at: TEXT (ISO datetime)
- UNIQUE(venue_id, date)

**Game table:**
- id: INTEGER PRIMARY KEY AUTOINCREMENT
- venue_night_id: INTEGER NOT NULL REFERENCES venue_nights(id) ON DELETE CASCADE
- name: TEXT NOT NULL
- playlist_json: TEXT NOT NULL (JSON array of songs)
- card_count: INTEGER NOT NULL DEFAULT 50
- pdf_path: TEXT (nullable, path to generated PDF)
- game_uuid: TEXT NOT NULL UNIQUE (UUID for API compatibility)
- sort_order: INTEGER NOT NULL DEFAULT 0
- created_at: TEXT (ISO datetime)
- updated_at: TEXT (ISO datetime)

Include:
- SCHEMA_SQL constant with CREATE TABLE IF NOT EXISTS statements
- Dataclass for each entity (Venue, VenueNight, Game) with from_row() classmethod
- create_tables(conn) function that executes SCHEMA_SQL
  </action>
