<task type="auto">
  <name>Task 1: Add pattern-aware progress calculation to GameState</name>
  <files>musicbingo_api/src/musicbingo_api/models.py</files>
  <action>
Add a new method `_calculate_pattern_progress(self, marked_positions: set[tuple[int, int]], pattern_type: PatternType) -> int` to GameState class.

Implement pattern-specific progress calculation:

1. **For FIVE_IN_A_ROW, ROW, COLUMN, DIAGONAL patterns:**
   - Calculate progress toward the "best" incomplete line
   - Check each possible winning line (5 rows, 5 columns, 2 diagonals)
   - For each line, count how many positions are marked
   - Return the MAXIMUM count across all lines
   - Example: Card has 4 in row 0 and 3 in column 2 → returns 4

2. **For FOUR_CORNERS:**
   - Count marked positions in corners set: {(0,0), (0,4), (4,0), (4,4)}
   - Return count (0-4)

3. **For X_PATTERN:**
   - Count marked positions in both diagonals combined (unique cells)
   - Diagonals share center (2,2), so total is 9 unique cells
   - Return count (0-9)

4. **For FRAME:**
   - Count marked positions in edge cells
   - Edges: row 0, row 4, column 0, column 4 (16 unique cells)
   - Return count (0-16)

5. **For FULL_CARD/BLACKOUT:**
   - Count all marked positions except free space
   - Return count (0-24)

Handle free space (2,2) correctly:
- Include in marked_positions if pattern requires it (X_PATTERN, diagonals)
- Don't include in FOUR_CORNERS or edge-only calculations
  </action>
