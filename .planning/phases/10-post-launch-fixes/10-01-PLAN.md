Modify the `generate_cards()` method to also export a complete game JSON file to the `games/` folder.

After existing card generation logic:
1. Build complete game JSON with all required fields:
   - `game_id`: The game's UUID (string format)
   - `name`: From `game.name` (already available in method)
   - `playlist`: Array of song objects from `game.playlist_json` - needs conversion to match game_loader expected format (song_id must be UUID format matching the cards)

   - This ensures playlist song_ids match the UUID keys in card `song_positions`

3. Save to `games/{sanitized_game_name}_{game_id_short}.json`:
   - Sanitize game name for filesystem (replace spaces/special chars with underscores)
   - Use first 8 chars of game_id for uniqueness
   - Use GAMES_DIR from game_loader.py (import it)

Do NOT modify the existing `data/generated/{game_id}/` export - that's for PDF download. This is an ADDITIONAL export for Host app compatibility.
  </action>
