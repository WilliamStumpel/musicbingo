Install Playwright and configure for the Music Bingo project.

Create root package.json (if not exists) or use existing one:
```json
{
  "name": "musicbingo-e2e",
  "scripts": {
    "test:e2e": "playwright test",
    "test:e2e:ui": "playwright test --ui",
    "test:e2e:debug": "playwright test --debug"
  },
  "devDependencies": {
    "@playwright/test": "^1.40.0"
  }
}
```

Run: npm install (or add to root if package.json exists)

Create playwright.config.js:
- baseURL: http://localhost:3000 (host app)
- Configure projects for chromium (primary)
- Set testDir to './e2e'
- Configure webServer to start API and both frontends:

  - Host: npm start in musicbingo_host on port 3000
  - Scanner: npm start in musicbingo_verify on port 3001
- Set timeout to 30s per test
- Retries: 1 on CI
