<task type="auto">
  <name>Task 1: Create manual testing protocol</name>
  <files>docs/MANUAL_TESTING.md</files>
  <action>
Create comprehensive manual testing protocol for pre-gig validation.

Structure:
1. Prerequisites
   - Devices needed (laptop, phone/tablet, TV/monitor)
   - Network setup (same WiFi, ngrok for HTTPS)
   - Test data (sample games in games/ directory)

2. Pre-Gig Checklist (30 min before)
   - [ ] Start API server
   - [ ] Start host app
   - [ ] Verify ngrok tunnel if needed
   - [ ] Test scanner connection via QR
   - [ ] Load test game
   - [ ] Quick scan test with printed card

3. Full Test Scenarios

   Scenario A: Game Prep (on laptop)
   - Create venue with logo
   - Create venue night
   - Add game with CSV playlist
   - Generate and download cards
   - Print sample page

   Scenario B: Game Hosting (on laptop)
   - Load game from dropdown
   - Mark 5 songs as played
   - Verify Call Board updates
   - Change pattern to Four Corners
   - Reset round
   - Verify songs cleared

   Scenario C: Scanner Verification (on phone)
   - Connect to server via QR code
   - Scan winning card QR
   - Verify green winner display
   - Scan non-winning card
   - Verify red non-winner display
   - Register card to player name
   - Verify registration in host app

   Scenario D: Player View (on TV)
   - Open player view from host
   - Verify call board displays
   - Mark song as played
   - Verify delayed reveal works
   - Trigger winner announcement
   - Verify celebration animation

4. Troubleshooting
   - Scanner won't connect: Check CORS, ngrok status
   - QR not scanning: Lighting, camera focus
   - Slow verification: Check network, API logs

Include estimated time for each scenario.
  </action>
