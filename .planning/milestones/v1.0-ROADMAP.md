# Milestone v1.0: Paper Card System

**Status:** SHIPPED 2026-02-01
**Phases:** 1-10
**Total Plans:** 33

## Overview

Complete application for running music bingo for a printed paper card game at venues. DJs prepare games in advance, print QR-coded bingo cards, play music via any player, and instantly verify winners with a phone scanner.

## Phases

### Phase 1: Local Backend Infrastructure

**Goal**: Backend runs on DJ's laptop, phone scanner connects via local WiFi for verification
**Depends on**: Nothing (first phase)
**Plans**: 5 plans

Plans:
- [x] 01-01: Local server startup and network discovery
- [x] 01-02: Game selector with 8 pre-loaded games
- [x] 01-03: Scanner PWA connection to local backend
- [x] 01-04: Connection QR code for scanner app
- [x] 01-05: Venue deployment infrastructure (Vercel + ngrok + one-click startup)

**Key Decisions:**
- CORS regex for private network IPs
- UDP socket to 8.8.8.8 for reliable local IP detection
- JSON game format matches card generator export structure
- localStorage for server URL persistence in scanner PWA
- ngrok auto-detection via localhost:4040/api/tunnels

### Phase 2: Card Printing System

**Goal**: Generate professional print-ready PDFs with 4 cards per letter page and venue branding
**Depends on**: Phase 1
**Plans**: 1 plan

Plans:

### Phase 3: Manual Playback Mode

**Goal**: Import playlists via CSV, mark songs as played from host or scanner, sync state via API
**Depends on**: Phase 1
**Plans**: 4 plans

Plans:
- [x] 03-01: CSV playlist import (Exportify format)

- [x] 03-03: Scanner checklist view (same features, mobile-optimized)
- [x] 03-04: API sync endpoints (mark-song toggle, game state polling)

**Key Decisions:**

## Milestone Summary

**Key Decisions:**
- Local-first over cloud - No venue WiFi dependencies, faster verification
- Manual Playback Mode pivot - Works with ANY music source (service-agnostic)
- DJ scans (not player self-scan) - Maintains showmanship and prize control
- Delayed song reveal on player screen - Rewards music knowledge, more engaging

**Issues Resolved:**
- Spotify API registration blocked - pivoted to manual playback
- iOS camera requires HTTPS - solved with ngrok + Vercel deployment
- Cross-window sync - solved with localStorage events

**Issues Deferred:**
- Game JSON not exported to games/ folder (workaround: manual copy)
- Prep → Host integration requires JSON file copy (fix in Milestone 2)

**Technical Debt Incurred:**
- Two disconnected storage systems (SQLite for Prep, JSON for runtime) - address in Milestone 2
